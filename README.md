# Cisco Packet Tracer Network Device Catalogue

A community catalogue of Cisco Packet Tracer network devices for searching, comparing and choosing devices by ports and features, with module compatibility and connection options across Packet Tracer versions 6, 7, 8 and 9.

[Open the catalogue](https://huytuph.github.io/packet-tracer-catalogue/)

## Data Policy

- Packet Tracer behaviour takes precedence over real Cisco hardware specifications.
- Partial or Unknown evidence is not assumed to confirm support. Verify build-critical ports, features and modules in your installed Packet Tracer version.
- Device availability is separate from capability verification. Evidence for one release does not guarantee every minor release in its major-version family.
- Unknown availability does not mean a device is absent. All versions combines evidence from different releases.
- Sources and verification status are retained with evidence-backed records.

See the [full data policy](docs/DATA_POLICY.md).
