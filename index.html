About this catalogue

Purpose

This catalogue is designed to help choose network devices inside Cisco Packet Tracer while building labs and assignments. It is not a general Cisco product catalogue. This independent project is not affiliated with or endorsed by Cisco.

Offline design

Everything required by the UI is stored in this repository. Double-click index.html. No Python, Node.js, database server, web server or internet connection is required for end users.

Data policy

Packet Tracer behavior wins when the simulator differs from real hardware. Partial and unknown records are shown rather than guessed. Real Cisco product specs are supporting reference data.

Master database

data/packet-tracer.db is the relational master database. data/catalogue-data.js is generated from it for reliable file:// browser operation.
